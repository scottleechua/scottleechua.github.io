Websites that I build and maintain.

Occasionally, I develop small websites for friends and colleagues:

  • blog.biancalesaca.com — an art process blog
  • dunnodowhat.com — newsletter of free / indie events in Singapore
  • komiks.space — an online space for Southeast Asian komiks
  • lawrenceypil.com — a writer’s portfolio
  • myleyantay.com — movie review blog
  • yamsmusic.com — a musician’s page

tech stack

Engine. I usually use Ghost when email or search is important, and Jekyll otherwise.

Editor interface. Ghost has its own delightful editor interface. For Jekyll, I’ve started using TinaCMS, which cleverly generates a Wordpress-esque editor interface for static sites right in the browser.

Monitoring. I use GoatCounter for free + open-source + cookieless analytics, and Betterstack’s free tier for uptime checks.

resources

  • For Ghost, read my blog post Self-hosting Ghost on Google Cloud.
  • For TinaCMS with Jekyll, clone my starter template tina-ghpages-starter.
